# Chat de texto via terminal

Este projeto tem como objetivo principal fixar e exercitar conceitos fundamentais de redes de computadores, incluindo:

- **Endereços IP**: Identificação única de dispositivos em uma rede.
- **Portas**: Pontos lógicos para comunicação entre aplicações.
- **Sockets**: Interface para comunicação entre processos via rede.
- **Protocolo TCP**: Protocolo de transporte orientado à conexão, garantindo entrega confiável dos dados.
- **Transferência de dados (bytes)**: Envio e recebimento de informações em formato binário.
- **Buffer**: Área de memória utilizada para armazenar temporariamente dados durante a comunicação.
- **Exceções de rede (como timeout)**: Tratamento de erros comuns em comunicação de rede, como tempo limite de resposta.

O projeto é uma ferramenta prática para entender como esses conceitos se aplicam no desenvolvimento de aplicações de rede utilizando a linguagem Python.
